# Doki Document Exporter

Консольная программа для выборочной выгрузки входящего документооборота из [Доки (Астрал)](https://astral.ru/help/doki/dlya-prodvinutykh-polzovateley/integratsiya-s-api-doki/).

Программа работает только на чтение: она не создаёт, не изменяет и не удаляет данные в Доки.

## Возможности

- скрытый ввод Bearer access token без записи на диск;
- произвольный период выгрузки;
- выбор одного или нескольких юридических лиц аккаунта;
- отдельный выбор одного или нескольких поставщиков для каждого юрлица;
- поиск организаций по названию или ИНН;
- скачивание юридически значимого ZIP-архива, подписей и служебных файлов;
- скачивание печатной PDF-формы первичного документа, например УПД;
- сохранение протокола, карточки, транзакций и истории;
- продолжение прерванной выгрузки без повторного скачивания готовых файлов;
- автоматические повторы при HTTP 408, 429 и временных ошибках сервера;
- CSV-реестр и SHA-256 для каждого файла.

## Требования

- Python 3.10 или новее;
- доступ к `https://api.1cdocs.ru`;
- действующий Bearer access token Доки.

Сторонние библиотеки не требуются.

## Быстрый запуск

### macOS

Дважды откройте `run_macos.command` либо выполните:

```bash
python3 -m doki_exporter
```

### Windows

Откройте `run_windows.cmd` либо выполните:

```powershell
py -3 -m doki_exporter
```

### Linux

```bash
python3 -m doki_exporter
```

## Порядок работы

1. Вставьте токен. Символы при вводе специально не отображаются.
2. Укажите начальную и конечную даты в формате `ДД.ММ.ГГГГ`.
3. Выберите юридические лица аккаунта.
4. Для каждого юрлица выберите поставщиков.
5. Проверьте сводку и подтвердите выгрузку.

Множественный выбор поддерживает номера и диапазоны:

```text
1,3,5-7
```

Команда `все` выбирает весь показанный список. Вместо номера можно ввести часть названия или ИНН.

## Результат

Структура каталога:

```text
exports/
└── 2024-01-01_2025-12-31/
    └── ИНН_Ваше юрлицо/
        └── ИНН_Поставщик/
            ├── export_index.csv
            ├── export_manifest.json
            └── incoming/
                └── дата_название_docflowId/
                    ├── documents.zip
                    ├── document.pdf
                    ├── protocol.pdf
                    ├── details.json
                    ├── transactions.json
                    ├── history.json
                    ├── summary.json
                    └── manifest.json
```

`documents.zip` содержит исходные юридически значимые документы и подписи. `document.pdf` является печатной визуализацией и не заменяет подписанный оригинал.

## Продолжение выгрузки

Повторите запуск с теми же датами, юрлицами и поставщиками. Программа проверит существующие файлы и запросит только отсутствующие или повреждённые элементы. ZIP проверяется как архив, PDF — по сигнатуре, JSON — разбором содержимого.

Список документооборотов запрашивается при каждом запуске: он нужен для сверки актуального состава. Уже сохранённые документы при этом не перекачиваются.

## Переменные окружения

Токен можно передать через окружение, чтобы не вставлять его вручную:

```bash
export DOKI_ACCESS_TOKEN='ваш-токен'
python3 -m doki_exporter
```

Дополнительные параметры:

- `DOKI_BASE_URL` — адрес API, по умолчанию `https://api.1cdocs.ru`;
- `DOKI_OUTPUT_DIR` — каталог выгрузки, по умолчанию `exports`.

Не добавляйте `.env`, токены и каталог `exports` в Git. Они уже перечислены в `.gitignore`.

## Авторизация

API использует JWT в заголовке `Authorization: Bearer ...`. Если выданный ключ не является готовым access token, обратитесь к документации по авторизации или поддержке Астрал. Публичная схема API доступна в [Swagger](https://api.1cdocs.ru/api/help/index.html).

python3 -m unittest discover -s tests -v

## Ограничения

- программа выгружает входящие документообороты выбранных поставщиков;
- доступность документов определяется правами токена;
- при длительном формировании архивов сервер может отвечать HTTP 408 — программа делает повторные попытки и сохраняет прогресс;
- API Доки может измениться независимо от этого проекта.
